## 0 一句话结论

把 §M.43 那套预注册形式（档位跑前固定、三次全新起服、池化相对偏差与它定义的 span）外推到 **MTDC（玉米雄穗）**
与 **GWHD（小麦穗）** 两个**未用过的计数域**，用 **11 个输入尺度档位**、每域每起服 250 项、**合计 16,500 次调用**：
**模型在两个域的每一档都答 `0`**（250/250；两个最大预算档 249/250）⇒ 每档池化偏差 ≈ **−100%** ⇒ span 仅
**0.02 pp（MTDC）/ 0.01 pp（GWHD）**。⇒ **两域都不落座**（与 `P2E_evidence_record.md` 里 detector 那行**同一失效模式**：
**答零通道饱和、输入尺度旋钮没有可动的东西**），**不作为 ordering 的反例**，并记为本文所报
"**域是主导变量**"的又一实例。

## 2.1 ★ **仪器混杂（必须与本判定一起读）**

探针**逐字复用**该仪器的冻结提示词（`pf_p0_probe.py` 的 `BASE_PROMPT`，md5 `e7a65fd47345c2fe040fa4d05a3b1d86`），
而那句提示词问的是**人数**（"请数出图片中的**人数**…"），**本实验未替换任何对象名词**。
⇒ 在玉米雄穗与小麦穗这两个非人类计数域上，答 0 有相当一部分是**指令与域不匹配的合理行为**，不能全归因于模型失效。
对照：§M.49 对**同两个域**做了**名词替换**并明文披露（"the object noun phrase … the probe asserts that this
substitution is the only difference"）。⇒ **能真正让这个旋钮在这两个域上落座的，是名词替换版的仪器**；
在它跑出来之前，本记录只主张"**这两域不落座**"，**不主张**关于其答零通道的任何结论。
（补充材料 §M.43 已同句写明这一混杂。）

## 3 ★ 退化证据（判定的关键，独立统计）

| 域 | 逐档答案分布（各 250 项） |
|---|---|
| **mtdc** | **11 档每一档都是 250/250 答 `0`**（两个最大预算档为 249/250 个 0 + 1 个 `1`） |
| **gwhd** | 同型：几乎每档 250/250 答 `0` |

⇒ `Σpred ≈ 0` ⇒ `dev ≈ −100%` 恒等 ⇒ **span 量的是地板，不是旋钮**。与 P2-E 的 detector 行（零样本检测器在密集池
每档只回收 1–6%）**同族**。两次都指向同一句：**跨域 ordering 只能落在"模型确实会答数"的域上**。

**133.3 项/分**（+5.5%，两者 `Waiting: 0`）⇒ **加并发买不到速度**。

## 5 口径红线与运行史

1. 可比性**限定为"同仪器 / 同模型 / 同几何"**；**不声称同档位网格**（新档位与放行梯子只在 4 个标签重合）。
2. **与 §M.43 上面四行不是同一次 session** ⇒ 该节 3.01 pp 同 session 噪声底**不适用**。
3. **不使用代理、不插值补层**；层数不足记 not covered。
4. 运行史（如实记）：① `15:05:11` 首次启动因 GPU 显存被前一个服务占用而**按守卫正确拒跑**，`15:05:40` 第二次成功；

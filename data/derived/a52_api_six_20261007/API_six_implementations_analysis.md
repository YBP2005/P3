# Count beyond legibility replicates across six API implementations

### A5-2「计数 × 可读性正交冻结刺激」API 对照臂结果

*6 个 API 模型 × 648 张冻结刺激 × 3 份输出契约 × 3 次重复 = 34,992 格；与本地三量化构建（b0 AWQ-4bit / b1 FP8 / b2 BF16）同判据并列。*

---

## 0. 一句话结论

**在控制可读性（半径 3/8/24 px、GaussianBlur σ=0/4/8、相邻圆心距/直径 1.45/1.15/0.85）之后，`count` 对六个 API 模型的答对率仍有极强的负向作用（β_std 从 -1.30 到 -0.57，全部 95% CI 远离冻结的「无实质作用」带 ±0.2）；API 臂因此与本地三构建**同向**，C4 判决同为 FAIL。但塌缩形状**依模型而异**：6 个里有 4 个在 c80 档仍以真值 80 为众数答案，2 个（grok-4.7、glm-4.6v）出现真正的退化塌缩，而本地三构建在 c32/c80 档是**完全塌缩**（答对率 1.9–2.6% / 0.5–0.7%）。⇒「count beyond legibility」在 API 臂**得到重复**，但其**幅度随模型能力显著衰减**，不能把本地臂的塌缩幅度当作所有实现的普遍性质。**

## 1. 设计与口径（两行）

响应量 `correct`：`pred` 为整数且 `|pred − n_dots_detected_gt| ≤ max(1, 0.05·n_dots_detected_gt)`；`abstain` / 无解析 / 未服务一律计 0（冻结判据 C3）。尺度为 log-odds（IRLS logistic），`count` 先 z 标准化 ⇒ β_std = β̂_count；95% CI 为 Wald。C4 判决：CI **完全**落在 ±0.2 内才可称「无实质作用」。以上**逐字复用**冻结件 `_a52_criteria_frozen.json`（md5 `758962a2643e1035698682abefec5748`）与冻结分析器 `a52_analyze.py`（md5 `bf873c5e7da083dae42cb379efe9af9d`）的 `is_correct` / `wilson` / `fit_logit`。

**每个模型用到的格（n）**：每模型设计上 3 合同 × 3 重复 × 648 图 = 5,832 格。grok-4.7 实际 5,817（15 格未服务）、gemini-3.8-flash 实际 5,805（27 格未服务）；其余 4 个模型 5,832 全。逐模型的 n 见 §3 表。

### 5.2 重复噪声会不会改变档位结论？**不会。**

1. **塌缩形状不变**：以 c80 为例，逐次口径的众数答案与多数口径的众数答案在 6/6 模型上相同（gpt-6.1-sol / qwen3.8-max / qwen3.8-flash / gemini-3.8-flash → 80；grok-4.7 → 0；glm-4.6v → 100）。
2. **档位排序不变**：c08 > c32 > c80 在 6/6 模型的**两套口径**下都成立。
3. **β 与 C4 不变，而且更保守/更极端**：多数口径的 |β| 在 6/6 模型上**不小于**逐次口径（逐模型放大倍数 1.12–2.66，均值 +57%、中位 +41%；grok-4.7 从 -1.296 放大到 -3.451，因为三次里常有一次塌缩到 0/低值，取众数后错得更彻底）。C4 判决在两套口径下同为 **FAIL（6/6）**。
4. **但重复噪声很大，必须写进限度**：逐模型不一致率 **33.38%–57.49%**，|Δ| 中位 **0–3** 但 P90 达 **8–43**，qwen3.8-flash 的 |Δ| 均值 22.6。⇒ 单次调用不能代表模型在该格的行为；本报告所有主数字都建立在 3 次重复池化（或取众数）之上。

## 9. 结论段

**(a) API 臂是否支持「count beyond legibility」？—— 支持，且是与本地臂相互独立的重复。**

六个 API 模型在**同一批 648 张冻结刺激**上、用**同一 `is_correct` 判据**、在控制 `radius / blur / overlap / contract` 之后，`count` 的标准化主效应 β_std 落在 **-1.30 ~ -0.57**，95% CI 全部远离冻结的「无实质作用」带 ±0.2（最靠近的 gemini-3.8-flash 上界 -0.449）。C4 判决 **6/6 + 池化 = FAIL**，C5（以布局为组 8 折）**6/6 PASS**，NC1/NC3 **PASS**。
这一点与本地三量化构建的结论**同向**：本地臂 β ≈ −4.2 ~ −4.5，同样 FAIL。两臂的差异在**实现轴**上（6 个不同厂商的 API 模型 vs 同一 32B 模型的 3 种数值格式），因此 API 臂提供了本地臂之外的一条**独立证据**，而不是同一证据的重复计数。

**(b) 但幅度与形状依模型而异，不能把本地臂的塌缩幅度外推。**

| | c08 | c32 | c80 | c80 形状 |
|---|---|---|---|---|
| 本地 b0/b1/b2 | 48.82%–50.46% | 1.90%–2.57% | 0.51%–0.72% | **完全塌缩**：众数 30（c32）→ 0（c80），各占 1/3 |
| API 6 模型 | 36.73%–61.42% | 3.40%–49.13% | 5.61%–42.44% | 4/6 **众数 = 真值 80**；grok-4.7 众数 0；glm-4.6v 过冲到常数 100 |

所以正确的表述是：**「count beyond legibility」是关于「count 在控制可读性后仍有实质作用」的定性命题，它在两臂都成立；而「大计数被压到某个常数」是该作用在特定（弱/量化）实现上的一种**表现形态**，不是普遍规律。** 本臂中 4/6 个 API 模型在 c80 档仍以真值 80 为众数答案，说明它们的失败是**精度衰减**；grok-4.7（众数 0）与 glm-4.6v（众数 100）才复现了常数塌缩。

**(c) 判据与不确定性（必须随结论一起写）。**

1. **判决方向是确定的**：所有 CI 的下界都 ≤ -0.687，距 ±0.2 带至少 1.2 个单位；C5 的逐折符号一致性为 1.00、不稳定判据全为 False；阴性对照 NC1（β 中位 0.0019）与 NC3（34950 行零不一致）都通过。这些都不依赖任何事后选择。
2. **幅度的不确定性很大**：重复调用的不一致率为 33.38%–57.49%，|Δ| P90 达 8–43；多数值口径把 |β| 逐模型放大约 1.12–2.66 倍（均值 +57%、中位 +41%）。因此本报告**不主张**任何关于 β 绝对大小的精确陈述；跨臂比较（API |β| ≈ b1 的 13%–31%，逐模型 14%、31%、13%、19%、20%、25%）只能作为**方向的量级参考**。
3. **跨臂比较混杂了模型能力**：API 臂是 6 个更强的专有模型，本地臂是同一 32B 开源模型的 3 种量化。「本地 |β| 更大」既可能来自量化损伤，也可能来自**任务难度相对模型能力的差异**。本臂的设计不能拆开这两者，因此**不把它读成「量化导致塌缩」的因果证据**。
4. **abstain 的处置影响合同层面的数**：`permit` 下 abstain 计 0（冻结约定），使高计数档的正确率被机制性压低；`count×permit` 的负交互主要由此产生。把 abstain 行整行剔除后，聚合 β 变动 ≤ 0.10，判决不变（§7）。
5. **两处口径冲突已披露**（`analysis_manifest.md` §5.1）：逐行 vs 多数值；预注册 3 格是否移出 C3 拟合池。两处都不改变 C4/C5 判决，本报告两套并列。

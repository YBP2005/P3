## 0. 一句话结论

**把输出契约换掉（允许弃答），"答 0"一律归零、"显式弃答"一律 100%——这一点在 AWQ-4bit 与 BF16
两种精度、st_a 与 ucf 两个密集域上完全一致；换措辞也完全一致。**
但**反证对照**（在语料本已作答的 item 上跑同一契约）揭示：**弃答是饱和的通道切换，不是按可确证性的
选择性释放**——稀疏域 st_b（语料上从未出零）在 permit 下仍弃答 **88.6%**。
⇒ 这条**加强**了"弃权是行为而非能力"的命题，但**不支持**用 permit 臂的弃答率去推断逐项可确证性。

## 1. 实验设计（单变量）

| 项 | 内容 |
|---|---|
| 目的 | 在**同一权重、同一引擎、同一提示词、同一解析器**下，只改**输出契约**，看"答 0"是否消失 |
| 引擎 | vLLM 0.29.0，单卡 H20-96GB；`--max-model-len 8192`、`max_pixels 1048576 / min_pixels 200704`、`--max-num-seqs 24`、`temperature 0`、`max_tokens 128` |
| 探针 | `/root/19b_e1_probe.py`（零池普查，6 臂）、`19c_probe_paraphrase.py`（换措辞，3 臂）、`19d_probe_nonzero.py`（反证对照，3 臂）。**图像编码/解析/结果列逐字复用 `06_dense_vlm.py`** |
| 抽样 | **不是遍历数据集**，而是从语料 `vlm_<ds>_base_whole.csv` 里按 `pred` 取值分池：19b/19c 取 `pred==0`（零池），19d 取 `pred!=0`（非零池）；按 gt 排序后等间隔抽；`--n 1000` 实为"最多 1000"，**池多大就跑多大（全池普查）** |
| 池大小 | st_a：零池 **103** / 非零池 **79**；st_b：零池 **0** / 非零池 **316**；ucf：零池 **180** / 非零池 **154** |
| ⚠ | **st_b 零池为空**（语料 base 臂在 st_b 上从不答 0）⇒ 19b/19c 在 st_b 必然空产出，故 exp.sh 只在 19d 上用 st_b |

### 1.1 六个契约臂（提示词原文见探针 P 字典）

| 臂 | 契约要点 |
|---|---|
| `base` | 数人数，"不要遗漏、不要重复"，只输出 JSON |
| `permit` | 无法逐个确证时**回答 abstain，不要猜测** |
| `bestA` | 必须给数值估计，并说明哪些部分无法分辨 |
| `bestB` | 必须给具体数字，不允许答 0 或拒答 |
| `bestC` | 先分块估计再相加，不允许答 0 或拒答 |
| `channel` | 三态通道：数字 / `cannot_judge` / `no_people` |

**换措辞臂**（`permitB`/`permitC`/`channelB`）：**响应词表与既有臂完全相同，只改指令措辞**（含一条英文），
故解析与弃答判定无需改动，实验变量干净。

## 3. 反证对照（非零池：语料**本已给出数字**的 item）★ 本次最重要的新发现

| 模型 | 数据集 | base | permit | channel |
|---|---|---|---|---|
| AWQ | st_a | 0 零 / 0 弃 (n=79) | **0 零 / 78 弃** | **0 零 / 78 弃** |
| AWQ | ucf | 3 零 / 0 弃 (n=154) | **0 零 / 154 弃** | **0 零 / 154 弃** |
| BF16 | st_a | 0 零 / 0 弃 (n=79) | **0 零 / 78 弃** | **0 零 / 78 弃** |
| BF16 | **st_b** | 0 零 / 0 弃 (n=316) | **0 零 / 280 弃（88.6%）** | **0 零 / 268 弃（84.8%）** |
| BF16 | ucf | 0 零 / 0 弃 (n=154) | **0 零 / 154 弃** | **0 零 / 154 弃** |

**读法（务必照此写，不要写成"选择性释放"）：**

1. **弃答是饱和的通道切换**：一旦契约提供 abstain 选项，模型在**大部分 item 上直接弃答**，与它能否作答无关。
   密集域 100%，**稀疏域 st_b 也有 88.6%**（st_b 是全实验最不密集的域，语料 base 臂上它**从未**出现过答 0）。
2. ⇒ **不能用 permit 臂的弃答率去推断"逐项可确证性"**：该臂的信息量被指令饱和掉了。
3. ⇒ 但这条**加强**了主稿"**弃权是行为，不是能力**"（L47）与标题"abstention dominates"的立场：
   如果弃权是能力驱动，它应当随密集度平滑下降；实测是在稀疏域仍近乎饱和。
4. **出零现象的域依赖**：base 契约下 st_b 出零 **0/316**，而 st_a/ucf 为 64–102/103 与 120–166/180
   ⇒ **"答 0"只出现在密集域**，这为"答 0 是密集场景下的契约产物"提供了域边界证据。

## 6. 对主稿的影响（**需要改口径的段落**）

| 位置 | 现文 | 建议 |
|---|---|---|
| **L47** | "abstention is a **behaviour**, not a capability" | ✅ **可由 E2 加强**：一旦提供 abstain 选项，弃答在密集域 100%、稀疏域 88.6% 饱和出现 ⇒ 与能力无关 |
| **L307–312（§3.6(d)）** | "Refusals are **gated by whether the prompt demands per-instance enumeration**… This is **first-person evidence** that abstention is triggered by loss of per-instance legibility" | ⚠ **需收窄**：E2 显示显式弃答**只在契约提供 abstain 选项时出现**（base 臂 0 弃答；permit 臂 100% 弃答）。**不得**再用该臂弃答率论证"逐项可确证性门控"——该臂已饱和。可改写为：契约决定**通道**，而通道一旦打开即近乎饱和 |
| **L149** | "abstention is gated by per-instance legibility rather than by object count" | ⚠ 同上：本条由语料代理证据支撑，**不能被 E2 的 permit 臂"加强"**，因为该臂不区分密度 |
| **L551** | "What gates abstention is **blur, not resolution**" | ⚠ 与 E2 无直接冲突（那条基于降采样实验），但**新增**"契约饱和"这一更强因素，建议在机制讨论处并列 |
| **L674–679（§7.7）** | "Mediated effect — no"（用切块把弃权率压到 0.0% 后效应不变） | ➕ **可加一条独立旁证**：E2 在**同权重**下仅改契约即把答 0 从 102/103 压到 0，而弃答升到 100% ⇒ 弃权率与"答 0"可被解耦，进一步支持"弃权率不是中介" |
| **L811** | "the channel through which a model declines to answer is set by the contract" | ✅ **E2 直接支持**，可升格为主要证据（而非仅措辞层面的观察） |

**新增可写入正文的两条事实**（建议放 §5.7 或 E2 专节）：
1. 契约效应在 **AWQ-4bit 与 BF16 两种精度**下**完全一致**（0 答 0、100% 弃答），⇒ 排除"这是某种量化伪影"。
2. base 契约下的出零率**随精度显著变化**（99.0% vs 62.1%；92.2% vs 66.7%），而契约效应不变
   ⇒ **出零是契约与精度的交互产物，契约是主因**。

## 7. 必须如实记录的局限

1. **AWQ 权重只量化了语言主干，视觉塔保持 FP16**。实测该权重为 `compressed-tensors` 的 `pack-quantized`，
   `num_bits 4`、**`group_size 32`**、symmetric、minmax；**448 个量化张量中属于视觉塔的为 0 个**
   （`ignore` 列表排除 `model.visual.*`）。而本任务是图像计数 ⇒ **本实验的"精度轴"只扰动了语言主干**。
   论文中不得表述为"整模型 4bit"。
2. **`st_b` 零池为空** ⇒ 19b/19c 在 st_b 上无产出，这是**设计使然**，不是遗漏。
3. **19d 探针的日志措辞错误**：它打印 `base 臂 pred==0 的 item 共 N 个`，实际统计的是 `pred!=0`。
   **数据正确，仅日志措辞错**；保留探针原样以维持与 E1 的可比性基线。
4. **reps>1 与普查写同名文件**（追加+按 item 去重）⇒ 统计时**必须剔除 `#r` 行**。
5. **仍在跑**：BF16 32B 的 ucf 换措辞臂尚未跑完（本文件中的 `permitB n=40` 是**进行中**的部分数据，
   不是不一致）。8B / Qwen2.5-VL-7B / InternVL2.5-8B 三块的零池普查、反证对照、换措辞、重复性随后进行。
6. **待补的精度阶梯**（正在下载/排队）：官方 **FP8**（已完成下载 35.53 GB）、**GPTQ-W4**（20.55 GB）、
   **AWQ-8bit**（37.48 GB）。三者将与 BF16 / AWQ-4bit 构成 **位宽 × 算法** 的 2×2：
   AWQ-4 vs AWQ-8 分离**位宽**；AWQ-4 vs GPTQ-W4 分离**算法**。

### 9.1 ★★ 决定性结果：显式拒答由**契约是否提供 abstain 选项**决定，而非"是否要求逐项枚举"

AWQ-32B（零池；st_a n=103、ucf n=180）：

| 臂 | 契约要点 | st_a | ucf |
|---|---|---|---|
| `base` | 数人数，不许弃答 | 102 零 / **0 弃答** | 166 零 / **0 弃答** |
| **`enum`** | **明确要求逐个枚举**，不许弃答 | 92 零 / **0 弃答** | 159 零 / **0 弃答** |
| **`locate`** | **"locate every person"**，不许弃答 | 99 零 / **0 弃答** | 155 零 / **0 弃答** |
| **`enumAbstain`** | 要求枚举 **+ 允许弃答** | **0 零 / 103 弃答（100%）** | **0 零 / 180 弃答（100%）** |
| `permit` / `channel` | 允许弃答 | 0 零 / 100% 弃答 | 0 零 / 100% 弃答 |

⇒ **三个枚举臂一律 0 显式弃答**，它们产生的是**答 0**；只有当契约**提供 abstain 选项**时才出现显式弃答，
且一旦提供即 **100% 饱和**。

**⇒ 主稿 §3.6(d)（L307–312）的归因与实测相反。** 原文称
"Refusals are **gated by whether the prompt demands per-instance enumeration** … This is **first-person
evidence** that abstention is triggered by loss of per-instance legibility"。
实测：**枚举要求 → 答 0（非拒答）**；**弃答由契约的可选性门控**。这一条应改写为与 L811
（"the channel through which a model declines to answer is set by the contract"）一致的表述。
**这是实质性错误，不是措辞问题。**

### 9.2 弃答的饱和性：跨模型、跨域均近乎 100%（非零池）

非零池 = 语料**本来给出了数字**的 item ⇒ 这些 item 上模型本可作答；若弃答随可确证性选择性发生，
此处应当低。实测：

| 模型 | st_a | st_b | ucf |
|---|---|---|---|
| Qwen3-VL-32B-AWQ-4bit | 78/79（99%） | — | **154/154（100%）** |
| Qwen3-VL-32B-BF16 | 78/79（99%） | 280/316（89%） | **154/154（100%）** |
| **Qwen2.5-VL-72B-AWQ** | **79/79（100%）** | — | **154/154（100%）** |
| **InternVL2.5-8B-AWQ** | **79/79（100%）** | **315/316（100%）** | **154/154（100%）** |

⇒ **弃答是饱和的通道切换，与逐项可确证性无关。** 4 个模型（含 72B 与跨族）一致。
⇒ 因此**不得**用 permit 臂的弃答率去推断逐项可确证性（前文 §3 的结论在扩域后进一步坐实）。

### 9.3 契约效应在航拍域同样成立

VisDrone（每图仅 17–22 个目标）：base **268/273 出零（98.2%）** → permit **0 出零 / 273 弃答（100%）**。

⇒ 两点推论：
1. **"答 0"并非密集场景专属**：航拍域 base 出零率（98.2%）与密集域 st_a（99.0%）几乎相同，
   且远高于同域 BF16。⇒ 出零是**具体量化构建**的特性（与 GPTQ-W4 的 8.7% 形成对照），
   而不是"目标多到数不清"的产物。
2. 契约效应在此域**完全复现**（0 出零、100% 弃答）。

### 9.7 附：语料 `abstain` 列是**关键词代理**，不是契约弃答

**故报告弃答率必须写清臂与措辞**（此结论与 §9.5c 末句"必须注明是哪个臂"一致，只是去掉了"必然更高"的暗示）。

**(b) ★修正 §10.3 的范围**：航拍非零池 `permit` 弃答率的跨条件散布由
"53–67%（3 个条件）"改为 **36.1% – 92.9%（8 个模型 × 2 域 = 16 格）**（完整表见 `out_v7c_subset.md` ②）。
⇒ "弃答饱和只成立于密集域"这条**更强**了：航拍域不仅不饱和，**跨模型散布达 57 pp**。

**(c) ★同时修正 §10.3 里的"99–100%"**：把三个密集域（st_a / st_b / ucf）合起来看，
`permit` 弃答率是 **88.6% – 100%（30 格中的 28 格）**，而非一律 99–100%——
低于 99% 的格子有 6 个（如 st_a 的 AWQ/BF16/GPTQ 各 78/79 = 98.7%、ucf 的 4B 145/154 = 94.2%、
ucf 的 30B-A3B 152/154 = 98.7%、**st_b 的 BF16 280/316 = 88.6%**）。
"饱和"这个判断不变（出口在密集域几乎不携带选择性），但引用时应给区间，不要给单点。

### 11.7 对主稿的影响（在 §6 / §9.4 之后新增的改口径项）

1. **§3.6(d) 归因**：现在有**同域内的判别性对照**（11.4）+ **条目级配对**（11.3）双重反证 ⇒
   必须改写为"**答 0 由契约是否提供 abstain 出口决定**"。
2. **摘要/§1 的普适性措辞**：按 11.2 收窄为两类（密集=构建特异、航拍=域特异），
   并**不得**把"答 0"写成 VLM 的普遍失效模式。
3. **弃答率数字**：凡出现"弃答率"处，必须标注**臂**（permit / channel）+ **措辞** + **域**；
   航拍域要给出区间 **36–93%**，不能给单点。
4. **凡引用 MoE 30B-A3B 的低出零率**，必须同时给出其 17–21% 未解析率。
5. **可复现性**：E2 的抽样是固定种子、跨模型同 item，这一点应写进复现说明（本轮已实证）。

### 11.8 局限（本轮新增）

- 航拍零池对 5 个新模型是**全池抽样 150**（池 273/154），而同域其余模型跑了全池；
  本文件统一用**公共 150 子集**给出可比读数，全池率另列（见 `out_v7c_subset.md`）。
